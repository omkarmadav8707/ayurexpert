§1 Problem Statement

IKS Concept as CS Concept: Classical Ayurvedic Tridosha theory, which classifies individuals into one of seven Prakriti constitutional profiles based on the relative dominance of Vata, Pitta, and Kapha doshas, is structurally isomorphic to a Production-Rule Expert System performing deterministic forward-chaining inference on a knowledge base.

The Ayurvedic physician (Vaidya) conducts Prashna Pariksha (structured patient interview) and Darshana Pariksha (visual observation), generating a set of observable facts (Lakshanas). These facts are then matched against a rule base derived from classical texts (Charaka Samhita, Ashtanga Hridaya) to arrive at a Prakriti classification.

This paper implements this process computationally as a deterministic forward-chaining rule-based expert system with 96 production rules, 24 observational domains, Certainty Factor combination, tiered domain weighting, and three sub-classifiers (Agni, Koshtha, Manas).

§2 Formal Algorithm Specification

The inference engine implements the following formal algorithm:

ALGORITHM AyurvedicPrakritiInference(O: ObservationVector) → PrakritiClass
// O = set of (questionId, answerId) pairs from Prashna/Darshana Pariksha

INPUT: O = {(q₁,a₁), (q₂,a₂), ..., (q₂₄,a₂₄)} // 24 observational facts
KNOWLEDGE BASE: R = {r₁, r₂, ..., r₉₆} // 96 production rules
THRESHOLDS: dualGap=6.0, balancedGap=4.0 // classification margins

PHASE 1 — Evidence Accumulation (Forward Chaining):
  FOR EACH rule rᵢ IN R:
    IF rᵢ.condition ∈ O // condition matches observation
    THEN FIRE(rᵢ):
      adjWeight ← rᵢ.weight × tierMultiplier[rᵢ.tier]
      score[rᵢ.dosha] += adjWeight
      CF[rᵢ.dosha] ← CF[rᵢ.dosha] + rᵢ.CF × (1 − CF[rᵢ.dosha]) // asymptotic combination

PHASE 2 — Score Normalization:
  total ← score[VATA] + score[PITTA] + score[KAPHA]
  pct[d] ← score[d] / total × 100 ∀d ∈ {VATA, PITTA, KAPHA}

PHASE 3 — Classification Policy:
  ranked ← SORT({VATA, PITTA, KAPHA}, score, DESC)
  IF max(score) − min(score) ≤ balancedGap → RETURN SAMA
  ELIF ranked[0].score − ranked[1].score ≤ dualGap → RETURN DVANDVAJA(ranked[0], ranked[1])
  ELSE → RETURN EKADOSHAJA(ranked[0])

OUTPUT: {prakritiClass, doshaScores, certaintFactors, firedRules, executionTime}

Formal Specification

Production Rule Base & Methodology

All 96 production rules derived from classical Ayurvedic texts. Search, filter, and inspect every rule's condition, effect, weight, and Sanskrit reference.

⚖️
Tiered Domain Weighting
Three tiers modulate evidence credibility:
  • Tier 1 — Somatic Invariants (1.25×): Frame, skin, hair, eyes, joints — life-long constitutional markers with highest epistemic weight.
  • Tier 2 — Physiological Core (1.0×): Digestion, metabolism, sleep, temperature, thirst — functional physiological indicators.
  • Tier 3 — Neuro-Cognitive (0.85×): Speech, memory, stress, personality — behaviorally influenced, lower baseline weight.
🔗
Certainty Factor (CF) Combination
Asymptotic Certainty Factor accumulation prevents overconfidence from redundant evidence:
CF_new = CF_old + CF_rule × (1 − CF_old)

Modeled after MYCIN's CF calculus. Ensures CF asymptotically approaches 1.0 rather than exceeding it from multiple confirming rules.
🏆
10-Class Directional Prakriti
Classification resolves into one of 10 granular categories:
  • 3 Ekadoshaja (single dominant): VATA, PITTA, KAPHA
  • 6 Directional Dvandvaja (dual, ordered): V-P, P-V, V-K, K-V, P-K, K-P
  • 1 Samadoshaja: Sama (balanced tridosha)
🧪
Sub-Classifiers
Three independent sub-classifiers provide deeper insight:
  • Agni Sub-Classifier: SAMAGNI · TIKSHNAGNI · VISHAMAGNI · MANDAGNI
  • Koshtha Sub-Classifier: KRURA (Vata) · MRIDU (Pitta) · MADHYAMA (Kapha)
  • Manasika Guna Classifier: SATTVA% · RAJAS% · TAMAS% with dominant Guna
